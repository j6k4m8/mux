Mux

Privacy

There is NO Mux server or third-party access.

Back to Mux

Access it requests
One scope, gmail.modify. That covers reading, labelling, archiving, and sending. It cannot permanently delete anything.
Where mail is stored
A SQLite database in your application support directory, on your own machine. Deleting that folder removes Mux completely.
Where mail is sent
Nowhere. Mux makes requests to Gmail / email APIs and to nothing else. No backend, no analytics, no crash reporting, no third parties, no advertising.
Where credentials live
The OS Keychain / password store. Nowhere else. Never on disk, etc.
Remote images
Images hosted by a sender are not fetched until you allow them, so opening a message does not tell anyone you read it.
Revoking access
Disconnect the account in Mux, or revoke it from your Google account permissions. Either stops all access immediately.
Future changes
I will never collect data, spin up a server to store analytics, or share anything. Mux is fully local.
